I · Animated

A line types itself out, the numbers appear, and the weekly bars grow in. Plays once per page view: a calm design that moves.

Data it needs: the current snapshot is enough. The animation must be CSS or SMIL inside the SVG, with no script: GitHub shows the card as an image, which never runs scripts.

An HTML mockup of the idea, not a theme: a theme draws the same design as an SVG string (see CONTRIBUTING.md, "Add a theme"). The numbers come from the public test fixture, test/fixtures/snapshot-casta-mere.json. The typing and counting use script here only to preview the idea. In SVG, use CSS keyframes or SMIL (counting digits up has no CSS equivalent: fade or slide the numbers in instead), end on the full, readable card, and honor prefers-reduced-motion.
