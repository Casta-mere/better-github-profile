K · Isometric skyline

The contribution calendar as a 3D city: each week a row of towers, one per day. The most eye-catching of the ideas; a bit of a showpiece.

Data it needs: daily calendar cells: removed from the v1 schema, which keeps weekly totals only. Needs a schema change (schemaVersion: 2) first.

An HTML mockup of the idea, not a theme: a theme draws the same design as an SVG string (see CONTRIBUTING.md, "Add a theme"). The numbers come from the public test fixture, test/fixtures/snapshot-casta-mere.json. The per-day heights are invented from the weekly totals to show the shape.
