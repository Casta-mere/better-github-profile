H · RPG character sheet

You as a game character: a level from all-time contributions, an XP bar to the next level, a class from the language mix, languages as skill pips, and achievement badges.

Data it needs: the current snapshot is enough.

An HTML mockup of the idea, not a theme: a theme draws the same design as an SVG string (see CONTRIBUTING.md, "Add a theme"). The numbers come from the public test fixture, test/fixtures/snapshot-casta-mere.json. The level, class and achievements are invented framing: a theme would define their rules from snapshot fields. Emoji depend on the viewer's fonts.
