    Your GitHub username comes first: the links in these steps go straight into your profile repository, so they turn on once it’s found.

    1. 1Create a token and save it as a secret

      Create a classic personal access token with the read:user scope (add the repo scope to include private work) and save it in your profile repository as the Actions secret STATS_TOKEN.

      1. 1a

        Create the token. Open GitHub’s new token page; the scopes it needs are already ticked: read:user, repo. Click Generate token and copy the token.

        Tip: set Expiration to No expiration. If the token expires, the cards are kept but marked stale until you add a new one.

      2. 1b

        optional Only if you belong to an organization that uses SAML SSO, for example your employer. On github.com/settings/tokens, open Configure SSO next to the token and Authorize the organization. Otherwise that organization’s private contributions aren’t counted as yours.

        GitHub Docs: Authorizing a personal access token for use with single sign-on

      3. 1c

        Add the secret. Open New repository secret in your profile repository and fill in:

        Name
        STATS_TOKEN
        Value
        the token from 1a

    2. 2Add the workflow

      Add workflow to your profile repository Update workflow

      Checking whether your profile repository already has the workflow…

      The button opens GitHub’s new-file page with the workflow filled in: click Commit changes. Or save it yourself as .github/workflows/profile-cards.yml.

      your profile repository already has a different workflow. GitHub can’t fill in an edit: copy the new workflow (Copy), open Update workflow, select all in the editor, paste, then Commit changes.

      ✓ Your workflow is already up to date. View it

      Cards from a previous theme stay in cards/; delete them if you like.

    3. 3Run it and check

      Run the workflow: click Run workflow there, and wait about a minute. Then check the setup.

      The secret itself can’t be checked: GitHub only shows secrets to a logged-in admin, so the check looks at the workflow run instead.

    4. 4Paste into README.md

      Once the check says the cards are ready, so the images exist: Edit README.md, paste the markup and commit. GitHub can’t fill in an edit, so copy the markup first.

      Changing the theme or cards also changes the file names: replace the README markup too.

      GitHub has deprecated the #gh-light-mode-only / #gh-dark-mode-only fragments in favor of <picture>. They still work, but may stop.
